## Install

```bash
$ npm install onesecret --global
```

## CLI

```bash
$ onesecret --help

  Generates regular expressions that match a set of strings.

  Usage
    $ onesecret [-gimuy] string1 string2 string3...

  Examples
    $ onesecret foobar foobaz foozap fooza
    $ jq '.keywords' package.json | onesecret
```
